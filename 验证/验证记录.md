## 1. 真实评论区导出

用户给出视频 `BV1FKsX6jEDH`（「您点的claude 已转接」），要求导出评论后一起重定规则。

```
GET https://api.bilibili.com/x/web-interface/view?bvid=BV1FKsX6jEDH  -> aid=117519448801460, 1069 条评论
GET https://api.bilibili.com/x/v2/reply/main?type=1&oid=<aid>&mode=3&next=N&ps=20   -> 热门分页
GET https://api.bilibili.com/x/v2/reply/main?type=1&oid=<aid>&mode=2&next=N&ps=20   -> 最新分页
GET https://api.bilibili.com/x/v2/reply/reply?type=1&oid=<aid>&root=<rpid>&pn=1&ps=20 -> 楼中楼
```

`/x/v2/reply/wbi/main` 返回 `-403 访问权限不足`（需 WBI 签名），老 `main` 接口可用。**36 次请求导出 504 条 / 426 个账号**（266 主评论 + 238 楼中楼）。

四个推翻 v1/v2 假设的发现：

| 发现 | 证据 | 影响 |
|---|---|---|
| `member.face` 全为空 | 0/426 | 头像聚类在线上拿不到，只能是可选佐证 |
| `member.sign` 是最强线索 | 229 个账号有签名，含明确 AI 自述 | v1 完全没采集 |
| 主题污染 | 视频讲 AI 冒充/中转站，Lv6 真人也在谈「是不是ai」 | 主题词不能作为证据 |
| 跨账号文本雷同 = 真人打窝 | `token 来！` 被 6 个账号一字不差复读 | 不能当 AI 模板证据 |

## 2. 人工标注（对话式，13 批）

用户要求「20 个 20 个问」，后又改为每批 60 条。工具 `samples/real/label.mjs`：支持「同意」采用默认初判、`3a 7h` 局部修改、整串字母覆盖、`全部h`。前 8 批每批 20，后 5 批每批 60/60/60/60/26。

**最终 426 个标签全部写盘**（`samples/real/labels.json`）：

| 标签 | 含义 | 数量 | 处置 |
|---|---|---:|---|
| `a` | AI 自动发评 | 42 | 隐藏 |
| `d` | 广告（带链接） | 6 | 隐藏（用户 11-08 确认「也可以屏蔽」） |

| `m` | 真人玩梗 / 钓鱼打窝 | 19 | 保留 |

用户拍板/补充的口径：
- Lv2/Lv3 + 签名明确自述 AI，即使没写「主人」也可直接拉黑
- Lv5/Lv6 人机共用只标记不隐藏
- 「鱼系昵称 + Lv2/Lv3 + 复述视频」也算自动发评（推翻 v2 极保守口径）

- 带链接的广告号也要屏蔽

## 4. v3 规则（闸门式）

处置顺序：

1. 白名单 / 屏蔽名单 / 人工处置
2. 外链推广 → `hide`
3. 真人硬保护（打窝复读、笑声 ≥2、真人自证、社区打卡短句、短评+具体口语） → `keep`
4. Lv4+ 且签名自述 → `mark`（人机共用）
5. Lv4+ 且无自述 → `keep`
6. Lv≤3 且只有模糊签名自述、无其它身份信号 → `mark`
7. **Lv≤3 且命中身份信号（核心/弱人设昵称、签名自述、人设口癖、对主人说话） → `hide`**
8. 其余 → `keep`

视频主题词一律不作证据。页面级群体统计只作展示与模型上下文，不参与定罪。模型复核只能确认或降级本地隐藏，不能把 `keep`/`mark` 升级成 `hide`。

## 7. 端到端验证（无头 Chrome）

puppeteer 请求拦截把 `https://www.bilibili.com/video/BV...` 与评论 API 指向本地夹具，扩展按真实 `content_scripts.matches` 注入。品牌版 Chrome ≥137 移除 `--load-extension`，改用 CDP `Extensions.loadUnpacked`。

**真实 Key 的 LIVE 运行：34 / 34 通过**；本地 mock 决策服务：33 / 33 通过。

新增的三类断言（对应本轮两个问题）：
- `隐藏后评论真实不可见（计算样式）`：不再只看 class，而是 `getComputedStyle` 的 `display/visibility/height/opacity` 全部不可见；
- `框架重置 className 后隐藏状态自动补回`：手动清掉 `baf-hidden` 与 `data-baf-hidden`，500 ms 后自动恢复；
- 拉黑链路：`面板外的评论行提供「拉黑」按钮`、`拉黑前弹出确认并说明会调用 B 站接口`、`拉黑失败时给出明确原因`、`拉黑失败时不会误写本地屏蔽名单`。

覆盖：评论异步加载、加载更多、展开楼中楼、切换视频、单条恢复且重扫后保持、判定依据、UID 白名单/屏蔽名单、真实分布页 12/12 隐藏且真人 0 误藏、接口状态提示、设置页真实调用、页面模型复核。

真实调用：设置页「测试连接」`499ms · usage={"input_tokens":2274}`；页面复核后台 `requests: 3`、`lastMs: 2250`、无错误，`apiStatus.ok: true`，`lastDecisions` 中 9 条带 `source: "model"`。

## 8. 过程中发现并修复的缺陷

| 缺陷 | 处理 |
|---|---|
| `manifest.json` 声明 `default_locale` 但缺 `_locales/` → Chrome 拒绝加载 | 移除声明 |
| 后台 service worker 用 `BiliAICF.Decision.*` 取 UMD 平铺导出 → 模型复核全线失败 | 改为平铺命名空间 |
| `MutationObserver` 被扩展自身节点触发 → 无限重扫 | 忽略自身节点 + `data-baf-state` 幂等 |
| 导航误触发 `resetForNewVideo`、DOM 兜底记录丢 `ctime/level/头像/签名/videoId` | 严格只认 BV/av/aid；`apiRecords` 结构化快照补全 |
| 多标签页同时写 `sessionComments` 到 storage 相互覆盖 | 改为仅本标签页内存维护 |
| 无头下 `chrome.permissions.request` 弹原生对话框挂住 CDP | 权限申请改为用户显式点击，保存只做 `contains` 并加超时 |
| `token\s*来` 把 AI 口癖「多跑点token来喂本鱼」误判成真人打窝 | 收紧为 `token 来！` 等孤立复读模式 |
| 真人共用默认头像被聚成 AI 头像簇 | 头像簇降级为纯佐证，不参与定罪 |
| 讨论「是不是 AI」的真人被 `meta_identity` 误标 | 主题词整体作废 |
| v2 把「对主人说话」当隐藏必要条件 → 真实召回 10.4% | v3 改为「低等级 + 身份信号」 |
| 低等级真人打卡/玩梗短评被 v3 误藏 | 补真人硬保护（笑声/自证/社区打卡/短评+口语） |
| **隐藏不生效：占位条出现但评论正文仍可见** | B 站用 React 管理 `className`，外部加的 `baf-hidden` 类在重渲染时被覆盖。改为 `data-baf-hidden` 属性 + 内联 `!important`（height/margin/padding/overflow/visibility/opacity），并让 MutationObserver 监听 `class`/`style`，属性被清掉时自动补回。e2e 断言从「查 class」改为「查 `data-*` + `getComputedStyle` 是否真的不可见」 |
| 行内按钮没有 `data-baf-act`，无法被选择器/测试定位 | `makeButton` 补上 `data-baf-act` / `data-baf-key` |
| **点「隐藏」没反应** | 两处原因：① `ensureActions` 的幂等键只比较 `decision`，而 DOM 兜底记录（`d:*`）被评论 API 记录（`r:*`）替换后 key 变了，按钮不会重建，仍绑在废弃 key 上；② 楼中楼 DOM 可能拿不到 `rpid`，key 与决策表对不上。修法：幂等键改为 `decision + '|' + key` 强制重建；按钮额外记录 `data-baf-rpid` / `data-baf-uid`，点击时按 `rpid`（其次 `uid`）反查当前决策；`applyAll` 顺带回收已脱离文档的 binding |

## 9. 密钥与隐私

- 全目录（含临时 profile、结果 JSON、日志）文本扫描 `sk-…`：**未发现落盘**。
- 扩展内 Key 仅存 `chrome.storage.session`，后台统一 `redact()`；设置页不导出 Key，有「清除」。
- 模型 `state` 只发公开昵称、评论文本片段（≤140 字）、等级、聚合数字与布尔，不发签名原文、头像 URL、UID、cookie、视频地址、浏览记录。
- 临时 Chrome profile、调试脚本、模型页渲染产物均已清理。
