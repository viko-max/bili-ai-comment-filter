# B 站 AI 评论过滤扩展 · 使用说明

识别并隐藏 B 站视频评论区里由 AI 账号自动发布的评论。隐藏只在当前浏览器内生效，可查看判定依据、恢复评论、按 UID 管理白名单与屏蔽名单。

**信息截止：2026-11-08。**

> **v3（当前版本）**：用户逐批标注了真实视频评论区 **426 个账号 / 504 条评论**，规则由这批真实标签推导，不再靠我猜。v2 的「极保守」口径（只有「签名自述 + 对主人说话」才隐藏）经真实标签验证召回仅 10.4%，已废弃。详见 `samples/real/标注分析与规则推导.md` 与 `验证/验证记录.md`。

## 二、快速开始

1. Chrome 打开 `chrome://extensions`，开启「开发者模式」，点「加载已解压的扩展程序」，选择 **`bili-ai-comment-filter/`**。
   > 品牌版 Chrome ≥137 移除了命令行 `--load-extension`，手动加载不受影响；自动化验证用 CDP `Extensions.loadUnpacked`。
2. 打开任意 B 站视频页。默认「纯规则模式」，不需要登录、不需要 API Key、不发外部请求。
3. 右下角悬浮按钮显示隐藏/标记数，点开可查看每条的判定依据，以及「恢复」「隐藏」「白名单」「屏蔽 UID」「拉黑」。被隐藏的评论折叠成占位条，占位条上直接有「判定依据 / 恢复 / 加白名单 / 拉黑」。
4. **模型复核默认关闭**：扩展图标 → 「设置 / 名单 / 判定依据」→ 勾选「启用模型复核」→ 填 API Key → 保存 → 「测试连接」。

### 隐藏与拉黑的区别

| | 生效范围 | 做法 | 需要登录 |
|---|---|---|---|
| **隐藏** | 仅当前浏览器 | 评论节点被真正压成 0 高度（`data-*` 属性 + 内联 `!important`），并插入「已隐藏」占位条 | 否 |
| **屏蔽 UID** | 仅当前浏览器 | 本地名单，该 UID 的评论永不显示 | 否 |
| **拉黑** | 你的 B 站账号 | 调 `x/relation/modify`（act=5）把对方加入你的黑名单，成功后同时写本地屏蔽名单 | **是**（依赖 `bili_jct`） |

隐藏为什么现在才真正生效：B 站用 React 管理 `className`，外部加的 `baf-hidden` 类会在重渲染时被覆盖（占位条还在、正文又露出来）。现在改用 `data-baf-hidden` 属性 + 内联 `!important`，并让 MutationObserver 在属性被清掉时自动补回。

拉黑是**写操作**：点击后先弹确认框，说明会调用 B 站接口；只做单条操作，不做批量；失败会明确提示原因（未登录 `-101`、csrf `-111`、已在黑名单 `22001`、操作频繁 `22008`、跨域/网络），且**失败不会误写本地名单**。

## 三、判定规则 v3（由真实标注推导）

### 标注告诉我们的三件事

| 发现 | 数据 |
|---|---|
| **等级是最强分界** | Lv2–3 的 77 个账号里 40 个 `a` + 6 个广告要隐藏；Lv4–6 的 349 个里 325 个是真人、只有 2 个要隐藏 |
| **v2 把「对主人说话」当必要条件是错的** | 42 个 `a` 里只有 **5%** 命中它；v2 在这批真实标签上召回仅 **10.4%** |
| **a 类与 h 类的文本画像** | `a` 类 71% 含鱼系昵称、67% 复述视频、50% 有人设口癖；`h` 类 **76% 是短评**、只有 8% 含鱼系昵称 |

标签分布：`a` 42（AI 自动发评，隐藏）、`d` 6（广告，用户确认也隐藏）、`s` 10（人机共用，只标记）、`h` 349（真人）、`m` 19（真人玩梗/打窝）。

### 处置闸门

| 顺序 | 条件 | 处置 |
|---|---|---|
| 1 | 白名单 / 屏蔽名单 / 单条人工处置 | 按用户 |
| 2 | 含外链推广（`.top` / `.store` / `https://` 等） | **隐藏**（与 AI 分开统计） |
| 3 | 真人硬保护：打窝复读（`token 来！`/`💰人来`/`🎣鱼来`/`二创来`/`赛博空军`）、笑声、真人自证、社区打卡短句、短评+具体口语 | **保留** |
| 4 | Lv4+ 且签名自述 AI/接管（人机共用） | **标记**（不隐藏） |
| 5 | Lv4+ 且无自述 | 保留 |
| 6 | Lv≤3 且只有模糊签名自述、无其它身份信号 | **标记** |
| 7 | **Lv≤3 且命中身份信号**（核心/弱人设昵称、签名自述、人设口癖、对主人说话/自动浏览复述） | **隐藏** |
| 8 | 其余 | 保留 |

**身份信号词**包括：昵称 `大肥鱼/肥鱼/小飞鲸/鲸鱼娘/白饭/龙娘/大小姐/GPT小龙娘/DeepSeek-Bot`，签名 `本账号由…运营/接管/已接入GPT/DSH/DeepSeek Harness/主人/共享账号`，文本 `本鱼/本鲸/白饭/鱼干/管饱/主人/替班/加班/窗口/工位/傲娇/鲸尾`。**视频主题词**（Claude / token / 冒充 / 额度 / 中转站 …）一律不作为证据 —— 真人也会讨论这些。

页面级统计（同族昵称规模、签名族、共享主题词、互 @ 链、时间聚集、跨账号模板雷同、DOM 头像簇）只作判定依据展示与模型上下文，**不参与定罪**。`member.face` 在公开评论 API 里全为空，头像聚类仅作可选佐证。

### 模型复核

只复核规则筛出的 `mark`/`hide` 样本，4 个结构化问题（`source` / `auto` / `evidence` / `action`）。模型**只能确认或降级**本地隐藏，不能把 `keep`/`mark` 升级成 `hide`；结论冲突即降级为可见的标记。`state` 只发公开昵称、评论文本片段（≤140 字）、等级、聚合数字与布尔，不发签名原文、头像 URL、UID、cookie 或浏览记录。

## 四、模型接入（已用真实 Key 实测）

```
POST https://maas-api.antdigital.com/v1/systemone
Authorization: Bearer <API Key>
Content-Type: application/json
{ "model": "lingdt-decision-1.0-27b", "state": {...}, "questions": {...} }
```

`errorCode: 0` 才算成功（HTTP 200 也可能失败）；`state` 按问题数放大 token 估算，超限返回 `request_tokens_estimate_exceeded`，实现里自动拆批。官方指南与模型页「API 调试」需登录，本次以真实接口实测替代；endpoint / 协议 / 模型 ID / 超时 / 批次 / 阈值全部可在设置页修改。

- **去重** 同一账号同一证据快照只调用一次；**限流** 每分钟/并发/会话总量三重
- **降级** 接口不可用 / 超时 / 解析失败 / 未设置 Key → 面板明确提示并回退纯规则
- **密钥** 只在 `chrome.storage.session`（内存级、重启即清），后台统一脱敏，不写入源码、导出或日志

## 五、复现实验

依赖只装在 `HY4测试/` 内，不装全局包。

```powershell
cd HY4测试
npm install
npm run eval:real          # 主评估：426 个真实标签 -> 验证/真实标注评估.md
npm run analyze:real       # 标注规律与候选规则对比 -> samples/real/标注分析与规则推导.md
npm run fetch:real -- 12   # 重新导出真实评论区（公开 API，无需登录）
npm run clusters:real      # 聚类 -> samples/real/clusters.md
npm run review:real        # 逐账号判定 + 待标注清单
npm run bench              # 仿真样本回归（离线复算）
npm run bench:fresh        # 重新发起真实模型调用（需 DTMAAS_API_KEY）
npm run e2e                # 无头 Chrome 端到端（模型走本地 mock）
$env:DTMAAS_API_KEY='sk-...'; npm run e2e   # 端到端 + 真实模型调用
```

对话式分批标注工具：`node samples/real/label.mjs <批次> "同意|3a 7h|全部h|整串字母"`，结果写 `samples/real/labels.json`。

> Key 只从环境变量读取，脚本不写入任何输出文件。

## 六、验证结果

| 项目 | 结果 |
|---|---|
| **真实标注集（主评估，426 账号）** | 正确隐藏 42 / 误藏 12 / 漏判 6；精确率 **0.778**、召回率 **0.875**、F1 **0.824**；规则耗时约 102 ms |
| 仿真对照（7 页 / 97 条） | 纯规则：漏判 21 / **误藏 0** / **真人误标 0** / 15.6 ms；模型复核：漏判 21 / 误藏 0 |
| 端到端（真实 Key） | **37 / 37 通过**，含设置页真实调用、页面模型复核、隐藏后计算样式确实不可见、`display:none` 彻底不可见、className 被重置后自动补回、点「隐藏」后真的折叠、拉黑确认与失败提示 |

> 真实标注集的 12 个误藏里，**4 个是 `s`**（人机共用本该只标记），**8 个是 `h`**；8 个 `h` 几乎全是批次 2 前半标 `a`、后半留默认 `h` 的同类鱼系低等级号 —— 属于标注内部不一致，不是规则能靠简单特征区分的。已整理在 `samples/real/标注冲突待复核.md`（18 条），确认统一口径后可再调规则。仿真样本口径（所有 `auto_*` 都该隐藏）与 v3 不一致，其漏判数只作回归参考。

## 七、已知限制与未验证项

- **标注冲突未复核**：`samples/real/标注冲突待复核.md` 的 18 条待确认；这是当前精度的主要上限。
- **拉黑的成功路径未在离线环境验证**：e2e 只验证了「确认弹窗 / 失败提示 / 失败不误写名单」。成功路径需要真实登录态，请在你已登录的浏览器里点一次「拉黑」确认；如果提示 `code -101` 说明页面未登录，`-111` 刷新页面重试，`22008` 是操作过于频繁。
- **v3 未在真实 B 站页面由我本人复核**：端到端用与真实 API 字段一致的本地夹具；真实组件头像 `img` 选择器、楼中楼 DOM 结构建议人工抽查。
- 公开 API 不返回 `member.face`，头像聚类半失效，只能依赖 DOM `img`。
- **模型页「API 调试」示例正文未直接读取**（登录墙），以真实接口实测替代。
- 未在真实页面长时间运行；虚拟滚动/分页、评论区改版、大量评论性能未验证。
- 免费额度、计费、跨地域网络状况未验证；接口不可用时已按纯规则降级。
